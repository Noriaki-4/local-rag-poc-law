# 条例制定・改正業務マニュアル

実際の条例案作成や法的判断では、自治体の例規、法制執務基準、関係法令、専門家確認を別途行う。

## 条例・規則・要綱の違い

条例は、地方公共団体が議会の議決を経て制定する自治立法である。
規則は、長その他の執行機関がその権限に基づいて定める規範である。
要綱は、行政内部の事務処理方針や運用基準を整理する文書として扱う。

制度化を検討するときは、住民の権利義務への影響、義務付けや制裁の有無、予算措置、既存例規との関係を確認する。

## 作業手順

### 1. 政策目的と制度化の必要性を整理する

政策目的、対象者、解決したい課題、想定する行政措置を整理する。
条例で定める必要がある事項と、運用で対応できる事項を切り分ける。

### 2. 条例・規則・要綱のいずれで定めるか判断する

住民の権利義務に直接影響する事項、義務付け、禁止、制裁、手数料等を含む場合は、条例化の要否を確認する。
内部手続や裁量基準にとどまる事項は、規則や要綱で足りるかを検討する。

### 3. 関係法令との抵触有無を確認する

国法、都道府県条例、既存の市区町村例規との抵触や重複を確認する。
上位法令の委任、条例で定められる範囲、既存制度との整合性を確認する。

### 4. 条例案の素案を作成する

目的規定、定義、対象、義務、手続、経過措置、施行期日を整理し、条文構成案を作る。
この段階の素案は検討材料であり、法的妥当性を断定しない。

### 5. 法規担当課へ例規審査を依頼する

素案、政策目的、関係法令調査結果、影響範囲、施行希望時期を添えて法規担当課へ相談する。
法規担当課の確認結果に基づき、条文表現や構成を修正する。

### 6. 庁内調整・パブリックコメント要否を確認する

関係部署、財政担当、情報公開・個人情報担当、住民対応部門との調整を行う。
住民生活に広く影響する場合は、パブリックコメント等の手続要否を確認する。

### 7. 議案として議会へ提出する

議案、提案理由、参考資料、施行期日、周知計画を整理し、議会提出手続を進める。
議会提出前に、最新の例規案と説明資料の整合を確認する。

### 8. 議決後、公布・施行手続を行う

議会で可決された条例案は、公布・施行手続を行う。
担当課は公布日、施行日、関係部署への周知、住民向け案内の要否を確認する。
