# 質問分解の独立レビュー

## 目的

元の質問と生成済みの質問分解を照合し、検索前に直すべき意味上の誤りを修正した全件を返します。

## 手順

1. 元の質問が求める法令上の確認事項を列挙します。
2. draftの各WorkItemが、そのうち一つだけを扱っているか確認します。
3. 回答方法の指定と法令上の確認事項を分けます。
4. 行為者を確認し、行為の対象がWorkItemの質問に残っているか確認します。
5. 各WorkItemについて`checks`の4項目を判定します。
6. falseになった点を直し、修正後の全WorkItemと回答方法の指定を返します。

## ルール

- 質問にある確認事項を削除せず、質問にない確認事項を追加しません。
- 「説明する」「根拠条文を示す」「簡潔に答える」等は回答方法であり、WorkItemにはしません。
- `action_actor`は規制対象となる行為をする者です。説明を求められた質問者という意味ではありません。
- 行為の対象となる者や物はWorkItemの`question`に残し、行為者へ置き換えません。
- 元のIDを維持します。法的な答え、検索語、Hypothesisは作りません。
- `checks`はdraftではなく、修正後のWorkItemを対象にします。4項目がすべてtrueになるよう修正します。
- `findings`には修正した意味上の問題だけを短く書きます。修正がなければ空配列です。
