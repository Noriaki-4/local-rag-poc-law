# 質問の要求分解

法令質問が明示する要求全体を、次の2つへ重複なく分けます。

## 出力

- `work_items`：それぞれ独立した法的結論を出し、完了判定できる確認事項
- `non_work_item_requirements`：独立した法的結論を要しないが、回答で守るべき明示要求

## 手順

1. 質問の主文と、「含めて」「あわせて」等で追加された要求を抽出します。
2. 独立した法的結論を要する確認事項だけを、1事項ずつWorkItemにします。
3. 各WorkItemの行為者と対象側の主体を`actor_scope`へ書き、その関係を`actor_relation`の`same`、`different`、`unknown`から選びます。
4. WorkItemへ入れなかった明示要求だけを`non_work_item_requirements`へ入れます。
5. 2つを合わせて元の質問の要求に漏れ、重複、追加がないことを確認します。

## ルール

- 1つのWorkItemでは1つの確認事項だけを扱います。
- 各WorkItemには、誰が、何を、何に対して行う質問かを明記し、元の質問にある限定条件を残します。
- 「〜したい」の省略された行為者は「質問者」のように補い、行為の対象・客体を行為者へ読み替えません。
- 「AのBを〜したい」では、AはBに関係する主体であり、行為者とは限りません。主語が省略され、Aと同一だと明示されていない場合は「Aとは別の質問者がAのBを〜する」として、二つの主体を区別します。
- `actor_scope`には「質問者はAとは別の行為者」のように、二つの主体の関係を書きます。質問だけでは同一・別主体を決められない場合は「不明」と書きます。
- `actor_relation`は、同一主体なら`same`、別主体なら`different`、質問から確定できなければ`unknown`です。
- 質問が行為者と、対象の発行者、所有者、所属先等を別の語句で示す場合は、別の役割としてWorkItemに残します。同一だと明示されていない二つの役割を統合しません。
- 行為者の法的立場が不明な場合は不明なまま残します。
- 根拠・出典・引用・対象時点・地域・出力形式は、それ自体に法的結論を要しない限りWorkItemにしません。
- 他のWorkItemの結論について根拠法令・条文を示す要求は、独立したWorkItemではなく
  `non_work_item_requirements`にします。根拠自体の法的性質が質問の確認対象である場合だけWorkItemにします。
- WorkItemにした確認事項を、説明要求として`non_work_item_requirements`へ重複させません。
- 「含めて」「あわせて」等で列挙された事項も、個別に法的結論を確認する必要があれば、それぞれ別のWorkItemにします。
- 「説明してください」のようにWorkItemへの回答そのものを求める表現は、別の要求として記録しません。
- 質問にない観点や要求は追加しません。
- 仮説、検索語、Tool要求は作りません。
