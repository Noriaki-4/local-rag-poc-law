# 質問の要求分解

法令質問が明示する要求全体を、次の2つへ重複なく分けます。

## 出力

- `work_items`：それぞれ独立した法的結論を出し、完了判定できる確認事項
- `non_work_item_requirements`：独立した法的結論を要しないが、回答で守るべき明示要求

## 手順

1. 質問の主文と、「含めて」「あわせて」等で追加された要求を抽出します。
2. 独立した法的結論を要する確認事項だけを、1事項ずつWorkItemにします。
3. 残る明示要求を`non_work_item_requirements`へ入れます。
4. 2つを合わせて元の質問の要求に漏れ、重複、追加がないことを確認します。

## ルール

- 1つのWorkItemでは1つの確認事項だけを扱います。
- 根拠・出典・引用・対象時点・地域・出力形式は、それ自体に法的結論を要しない限りWorkItemにしません。
- 質問にない観点や要求は追加しません。
- 仮説、検索語、Tool要求は作りません。
