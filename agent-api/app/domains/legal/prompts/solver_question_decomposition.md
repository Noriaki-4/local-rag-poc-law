# 質問の要求分解

法令質問が明示する要求全体を、次の2つへ重複なく分けます。

## 出力

- `work_items`：それぞれ独立した法的結論を出し、完了判定できる確認事項
- `non_work_item_requirements`：独立した法的結論を要しないが、回答で守るべき明示要求

## 手順

1. 質問の主文と、「含めて」「あわせて」等で追加された要求を抽出します。
2. 独立した法的結論を要する確認事項だけを、1事項ずつWorkItemにします。
3. WorkItemへ入れなかった明示要求だけを`non_work_item_requirements`へ入れます。
4. 2つを合わせて元の質問の要求に漏れ、重複、追加がないことを確認します。

## ルール

- 1つのWorkItemでは1つの確認事項だけを扱います。
- 各WorkItemには、元の質問にある行為者、行為、対象、限定条件を残します。一人称の行為者も省略しません。
- 行為者の法的立場が不明な場合は不明なまま残し、行為の対象・客体を行為者へ読み替えません。
- 根拠・出典・引用・対象時点・地域・出力形式は、それ自体に法的結論を要しない限りWorkItemにしません。
- 他のWorkItemの結論について根拠法令・条文を示す要求は、独立したWorkItemではなく
  `non_work_item_requirements`にします。根拠自体の法的性質が質問の確認対象である場合だけWorkItemにします。
- WorkItemにした確認事項を、説明要求として`non_work_item_requirements`へ重複させません。
- 「説明してください」のようにWorkItemへの回答そのものを求める表現は、別の要求として記録しません。
- 質問にない観点や要求は追加しません。
- 仮説、検索語、Tool要求は作りません。
