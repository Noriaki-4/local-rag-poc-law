# 法令調査Solver：質問の要求分解

## 目的

元の質問に含まれる要求を、法令本文の調査が必要な法的論点と、回答の示し方に分けます。

## 完了条件

- 質問が求める法令上の条件、範囲、例外、手続等の内容が、1つのWorkItemに1件ずつ分かれている。
- `work_items`と`non_work_item_requirements`を合わせると、元の質問に漏れ、重複、追加がない。

## 手順

1. 元の質問から、明示された要求を取り出します。
2. 答えるために法令本文を調べる必要がある要求ごとにWorkItemを作ります。
3. 行為者が明確な場合だけ、その役割を`action_actor`へ記録します。明確でなければ`不明`とします。
4. 残った回答の示し方を`non_work_item_requirements`へ記録します。

## ルール

### WorkItem

- 法令が何を求め、認め、禁じ、定義し、又は例外とするかを確認する要求を、法的論点とします。
- `work_items[].question`には、法的論点を自然言語の問いとして1件書きます。
- 複数の法的論点がある場合は、WorkItemを分けます。
- 元の質問の意味を変えず、結論に必要な前提を残します。
- 質問中の背景や程度を示す表現を、質問が明示していない法的基準へ置き換えません。例えば、日常語の人数・数量表現から、法令上の人数・割合・数値基準を新しい論点として推測しません。
- 「説明」「列挙」「示す」等の表現であっても、法令の内容を問う要求はWorkItemにします。

### 行為者

- `action_actor`には、質問から行為者が明確な場合だけ、その役割を書きます。具体的な人物名は不要です。
- 行為者が明確でない場合は、推測せず`不明`とします。

### その他の要求

- `non_work_item_requirements`には、根拠条文・出典・引用の提示や、文体・長さ・表等の出力形式の指定だけを書きます。
- 法的根拠の有無又は内容自体について結論を求める問いは、法的論点としてWorkItemへ書きます。
