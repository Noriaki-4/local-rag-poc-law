# 行為者だけを使う検索候補選別テスト

## 目的

各Caseについて、WorkItemの確認事項と行為者を直接検証できるArticleだけを選びます。

## 手順

1. `question`で確認する行為と条件を読みます。
2. `action_actor`と、各候補が規律する主体を比較します。
3. 主体、行為、条件が一致する候補を`selected_article_ids`、それ以外を`deferred_article_ids`へ入れます。

## ルール

- 同じ対象物や制度を扱うだけでは選びません。
- 行為者ではない別の者へ義務を課す候補は選びません。
- 全候補IDをどちらか一方へ入れます。
- 法的回答や新しい候補は作りません。
