## 出力前の確認

1. 各検索要求の`hypothesis_ids`が、`work_item_id`と同じWorkItemに属するか確認します。
2. `purpose`は確認内容の説明、`query`は制度名を含む短い法令用語・法令表現の組合せになっているか確認します。`query`が質問又は`purpose`の言い換えなら、法令本文の義務又は権限を表す語へ修正します。
3. `gaps`があればその内容を、空なら未検証の`statement`を検索語の中心にしているか確認します。WorkItemに明示された確認事項を、より広い検索語へ置き換えて落としません。
4. 同じ起点規定の複数Hypothesisを別検索にした場合は、法令見出し語を組み合わせた1検索で同じ候補を探せないか確認します。
5. 同じHypothesis IDが複数の検索要求に入っている場合は、検索語を1件にまとめます。
6. `doc_types`が今回必要な検索対象だけを含むか確認します。
7. 問題があれば修正してから、schemaに従う出力だけを返します。
