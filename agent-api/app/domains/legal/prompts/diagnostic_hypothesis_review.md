# 法的仮説の独立レビュー

## 目的

元の質問とWorkItemを基準に、生成済みHypothesisを検索に使える法的な予想へ修正した全件を返します。

## 手順

1. 各WorkItemについて、何が確認できれば完了するかを読み取ります。
2. draftの`statement`が、行為者、行為、対象と、検索すべき法的な判定軸を表しているか確認します。
3. 未確認の具体値・条件・例外類型を`gaps`へ分けます。
4. 各Hypothesisについて`checks`の4項目を判定します。
5. falseになった点を直し、修正後の全Hypothesisを返します。

## ルール

- Hypothesisは検索前の予想であり、法的な答えの断定ではありません。
- 「特定の条件がある」「法令で定められている」だけで終えず、人数、同意、期間、行為方法等、検索語へ変換できる判定軸を示します。
- 正確な数値、条番号、結論を知らなければ作りません。未確認内容を`gaps`に書きます。
- 「根拠条文を示す」等の回答方法は`gaps`にしません。
- WorkItemに明記された行為者と対象関連主体を維持します。
- 一つのHypothesisへ独立した命題を詰め込みません。
- 元のIDと所属WorkItem IDを維持します。
- `checks`はdraftではなく、修正後のHypothesisを対象にします。4項目がすべてtrueになるよう修正します。
- `findings`には修正した意味上の問題だけを短く書きます。修正がなければ空配列です。
