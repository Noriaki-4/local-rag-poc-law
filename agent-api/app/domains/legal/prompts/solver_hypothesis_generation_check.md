## 出力前の確認

1. 提示されたWorkItemにHypothesisが1件以上あるか確認します。
2. 現在のWorkItem自身が適用除外又は例外を問うか確認します。成立条件、対象範囲又は手続を問うだけなら該当しません。
3. 該当する場合は、未知の除外事由を作らず、指定された2つの構造仮説を必要に応じて別々に書いたか確認します。後続の検索要求を分ける必要はありません。
4. 該当しない場合は、`statement`が法令本文によって支持又は否定できる暫定的な結論か確認します。
5. `statement`に「特定の条件」「特定の場合」等の内容のない表現が残っていないか確認します。
6. 例外以外の複数の種類を問うWorkItemを、1つのHypothesisだけで済ませていないか確認します。
7. 根拠法令名、条文番号、検索語、検索作業を追加していないか確認します。
8. 問題があれば修正し、schemaに従う出力だけを返します。
