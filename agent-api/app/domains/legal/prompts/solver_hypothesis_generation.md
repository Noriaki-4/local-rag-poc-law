# 法令調査Solver：法的仮説の立案

## 目的

提示されたWorkItemについて、検索候補となる法的命題を作ります。

## 完了条件

- 提示されたWorkItemにHypothesisが1件以上ある。
- `statement`が、法令本文によって支持又は否定できる暫定的な結論になっている。
- `statement`から検索対象を考えられる具体性がある。
- WorkItemにない法的論点が追加されていない。

## 手順

1. WorkItemを確認します。
2. 法的論点に対する暫定的な結論を`statement`に書きます。
3. 複数の種類や例外を問うWorkItemでは、1件で終えず、具体的な候補ごとにHypothesisを分けます。

## ルール

### `statement`

- WorkItemと一般的な法的知識から、誤り得る暫定的な結論を書きます。
- 法令本文によって支持又は否定できる1つの命題にします。
- 仮説なので誤りは許容されます。確認済みの事実として扱いません。
- 「特定の条件」「特定の場合」「特定のもの」「法令で定める」のような、内容のない表現でWorkItemを言い換えません。
- 種類や例外を複数問われた場合は、具体的な候補を複数返します。
- 根拠法令名、条文番号、検索語、検索作業は書きません。
