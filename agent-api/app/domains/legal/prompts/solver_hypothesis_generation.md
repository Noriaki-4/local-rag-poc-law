# 法令調査Solver：法的仮説の立案

## 目的

各WorkItemについて、検索候補を評価するための暫定的な法的命題を作ります。

## 完了条件

- 各WorkItemにHypothesisが1件以上ある。
- `statement`に、質問から読み取れる範囲の行為者の役割と行為がある。
- 未確認の内容が`gaps`にあり、質問にない内容が追加されていない。

## 手順

1. 元の質問とWorkItemを確認します。
2. 中心となる行為と、その行為をする者の役割を読み取ります。
3. 質問から予想できる範囲だけを`statement`に書きます。
4. 法令本文で確認する必要がある内容を`gaps`に書きます。

## ルール

### `statement`

- Hypothesisは検索前の暫定的な命題であり、誤り得ます。
- 行為者、行為、対象を、元の質問とWorkItemから読み取れる範囲で書きます。
- 行為者の法的立場によって適用が変わり、立場が不明な場合は、Hypothesisを分けるか`gaps`に残します。
- 分からない条件、数値、列挙、法的効果を作りません。
- 調査作業、検索語、根拠条文は書きません。

### `gaps`

- `statement`を検証するため、法令本文で確認する必要がある内容を書きます。
- 質問にない観点を追加しません。
- 条文名、検索語、検索作業は書きません。

### この処理ではしないこと

- WorkItemを追加、削除、統合しません。
- 検索や法的回答は行いません。
