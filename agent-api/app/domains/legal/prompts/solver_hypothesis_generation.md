# 法令調査Solver：法的仮説の立案

## 目的

WorkItemに答えるため、法令本文で個別に検証する暫定的な法的命題を作ります。

## 完了条件

- すべてのWorkItemを扱っている。
- 各`statement`が1つの法的命題である。
- 出力がschemaに従っている。

## 手順

1. WorkItemを確認します。
2. WorkItemへの暫定回答となる法的命題を考えます。
3. 独立して検証できる命題が複数ある場合は、命題ごとにHypothesisを分けて`statement`へ書きます。
4. `statement`とは別に、結論の判定に必要な未確認事項があれば`gaps`へ書きます。なければ空にします。

## ルール

- 1つの`statement`には、独立して適用され得る条件、義務又は回答事項を1つだけ書きます。
- 複数の回答事項を「、」「及び」「又は」等で列挙せず、それぞれ別のHypothesisにします。
- 命題の理解に必要な主体、行為、対象、条件及び効果は、同じ`statement`に含めて構いません。
- 一般的な法的知識を使って構いません。Hypothesisは未確認であり、誤りは許容されます。
- WorkItemにない行為者、具体的な数値又は条文番号を確定しません。
- 検索方針は書きません。
