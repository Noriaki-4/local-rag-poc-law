# 法的仮説の立案

入力済みの各WorkItemについて、法令検索の対象を選べる暫定的な法的命題を作ります。

## 手順

1. 元の質問と各WorkItemを確認します。
2. 各WorkItemに、その完了判定に必要なHypothesisを1件以上作ります。
3. 各Hypothesisについて、行為者と対象に結び付く主体を`actor_scope`へ書き、WorkItemの`actor_relation`を保ちます。
4. 命題のうち、法令本文でまだ確認すべき具体的内容を`gaps`へ分けます。

## ルール

- WorkItemを追加、削除、統合しません。
- Hypothesisは未確認で誤り得る暫定回答です。質問の言い換えではなく、主体、行為、法的効果、適用を分ける判定軸を含めます。
- 各Hypothesisの`statement`には行為者を名詞で明記し、省略主語にしません。
- 規律を受ける行為者と、行為の対象・客体を区別します。WorkItemで別の役割として示された行為者と、対象の所有者、発行者、所属先等を統合しません。`statement`にも両者の関係が分かる形で残します。
- WorkItemが「Aとは別の質問者がAのBを〜する」と区別している場合は、`statement`でも二つの主体を明記し、Aを行為者へ置き換えません。
- WorkItemの`actor_scope`を主体関係の正本として使い、Hypothesisの`actor_scope`へ同じ関係を保ちます。
- WorkItemの`actor_relation`を変更せず、Hypothesisの`actor_relation`へコピーします。
- `actor_scope`は単なる人物名ではなく、「質問者はAとは別の行為者」のように主体間の関係を書きます。法的立場が質問だけでは分からない場合は「不明」と書きます。
- 行為者の法的立場が質問だけでは確定せず適用規定が変わり得る場合は、立場ごとのHypothesisに分けるか、未確定の立場を`gaps`に残します。
- 正確な値や列挙が不明なら推測せず、人数、割合、期間、行為類型等の確認すべき判定軸を示します。
- 「一定の条件」「特定の範囲」「法令上の手続」だけで終わらせません。
- `gaps`には未確認の法的内容を書き、条文名、検索語、検索作業は書きません。
- 根拠条文やArticle IDを推測しません。
