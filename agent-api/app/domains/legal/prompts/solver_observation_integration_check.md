## 出力前の確認

1. 各判定が、主体・行為・対象・条件の一致する提示本文とEvidence IDに基づくか確認します。
   列挙中の別の要件又は例外を、確認対象の根拠にしていないか確認します。
   候補要約と本文が別の規律を示す場合、その本文をHypothesisの根拠にしていないか確認します。
   同じ数値や制度名だけを理由に、異なる法的効果を対応付けていないか確認します。
2. 各`gaps[]`を本文と個別に照合し、下位規範へ委ねられたままの内容を削除していないか確認します。
3. 入力外のHypothesisを変えず、再試行では直前出力の違反箇所以外を変えていないか確認します。
4. WorkItem、下位規範確認、次の検索、Cycle移行、最終回答を出力していないか確認します。各IDの更新は1件にまとめます。
