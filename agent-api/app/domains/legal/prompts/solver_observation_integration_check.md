## 出力前の確認

1. 各判定が、主体・行為・対象・条件の一致する提示本文とEvidence IDに基づくか確認します。
2. `unresolved`では確認済みEvidenceを残し、本文で未確認の内容だけを`gaps`に残したか確認します。
3. WorkItemを閉じる場合、その質問へ選択Evidenceから回答でき、判定済みのbasis Hypothesisがあるか確認します。
4. 入力外の状態を変えず、再試行では直前出力の違反箇所以外を変えていないか確認します。
5. 下位規範確認を行わず、次の検索、Cycle移行、最終回答を出力していないか確認します。各IDの更新は1件にまとめます。
