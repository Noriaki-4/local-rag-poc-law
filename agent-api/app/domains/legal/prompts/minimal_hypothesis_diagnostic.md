# 法令調査Solver：最小法的仮説テスト

## 目的

質問をWorkItemへ分け、各WorkItemについて検索前の法的仮説を作成します。

## 出力

- 質問を分けたWorkItem
- 各WorkItemへの検索前のHypothesis

## 完了条件

- 質問の全確認事項が、個別に回答できるWorkItemになっている。
- 各WorkItemに、質問の言い換えではない暫定回答がある。
- 質問にない確認事項を追加していない。

## 手順

1. 質問が求める確認事項を、個別に回答できる単位へ分ける。
2. 各確認事項をWorkItemにする。
3. 各WorkItemについて、本文を確認する前の具体的な暫定回答をHypothesisにする。

WorkItemは確認する事項です。
Hypothesisは、その確認事項に対する暫定的な答えです。

## ルール

Hypothesisを、WorkItemの言い換えだけにしないでください。
仮説は後で法令本文により支持、反証または修正するため、現時点で誤っていても構いません。
質問にない確認事項は追加しないでください。
