# 法令調査Solver：Hypothesisの見直し

## 目的

現在のCycleで取得した本文を確認し、既存Hypothesisの代わりに検証すべき別の結論又は適用関係が判明した場合に限り、新しいHypothesisを追加します。

## 出力

- `add_hypotheses[]`：追加する新しい命題。独立した未解決事項がなければ空配列
- `decision_reason`：追加または追加しなかった理由の要約

## ルール

- 取得本文が既存Hypothesisを反証し、又はその前提と異なる法的仕組みを示した場合だけ追加します。
- 提案内容が既存Hypothesisの`statement`又は`gaps[]`に含まれる場合は追加しません。
- 既存Hypothesisの未確認事項を詳しくした内容や、その結論を支える個別要件は、新しいHypothesisにしません。
- 取得本文に別の義務、条件、例外、定義又は参照があるというだけでは追加しません。既存Hypothesisを保ったまま説明できる内容は追加しません。
- 取得本文だけで確認済みの内容や、利用者の具体的事実の確認は追加しません。
- 既存Hypothesisの`statement`は変更せず、同じIDを再利用しません。
- WorkItemの範囲を周辺の義務や手続へ広げません。WorkItemの言い換え、検索語や検索方針の変更、一般的な可能性だけでは追加しません。
- 各提案は入力にある既存WorkItemのIDを1つ指定します。
- `evidence_ids[]`には提案の必要性を直接示す最小限の取得済みEvidence IDだけを指定します。
- 追加する命題は未確認として扱い、確認が必要な具体的事項を`gaps[]`へ置きます。
- 既存の本文評価やWorkItemの完了状態を変更しません。
