## 出力前の確認

1. 全`search_candidates[]`を入力順に1回ずつ評価し、Article IDに重複・余分・欠落がないか確認します。
2. 各`summary`が、提示された見出しと検索抜粋だけに基づいているか確認します。
3. 各`matched_hypothesis_ids`が、本文取得候補と同じ法的論点を調べるHypothesisだけを参照しているか確認します。
4. 同じ制度名や語句があるだけの本文取得候補や、別の規律を扱う本文取得候補を対応付けていないか確認します。
5. 行為者の一致、本文取得候補の最終選択、Hypothesisの正否を判断していないか確認します。
